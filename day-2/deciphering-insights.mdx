**Duration:** 15 minutes

## How to read a dashboard

Ask these four questions of any chart:

1. **What is being measured?** (Check the axes and the aggregation: average, sum, count.)
2. **What is being compared?** (Which dimension slices it?)
3. **Where are the clusters, gaps and outliers?**
4. **What would I want to ask next?**

## Form a hypothesis

A good hypothesis names a **feature**, a **direction** and ideally a **size**, and is based on what you actually see.

<Tabs>
  <Tab title="Template">
    *When I filter to ______, the viral share is ______ compared with ______, which suggests that ______ matters for going viral.*
  </Tab>
  <Tab title="Example">
    *When I filter to the "pop" genre, the viral share is higher than for "classical", which suggests genre matters for going viral.*
  </Tab>
  <Tab title="Weak vs strong">
    **Weak:** "Energy matters."

    **Strong:** "Viral tracks cluster at high energy and mid-to-high valence in the scatter plot."
  </Tab>
</Tabs>

export const HypothesisBuilder = () => {
  const features = ["danceability", "energy", "loudness", "speechiness", "acousticness", "instrumentalness", "liveness", "valence", "tempo"];
  const visuals = ["the scatter plot", "the genre bar chart", "the viral share card", "the genre slicer"];
  const [f, setF] = useState("");
  const [d, setD] = useState("");
  const [v, setV] = useState("");

  const sel = "ml-2 px-2 py-1 rounded-md border border-zinc-300 dark:border-zinc-600 bg-transparent";
  const ready = f && d && v;
  const checks = [[f, "Names a feature"], [d, "Gives a direction"], [v, "Points to evidence"]];
  return (
    <div className="my-6 rounded-xl border border-zinc-200 dark:border-zinc-700 p-4">
      <p className="font-semibold m-0">Try it: build a hypothesis</p>
      <p className="text-sm mt-1">Fill in the blanks using what you see on your dashboard.</p>
      <div className="grid gap-2 text-sm">
        <label>Feature
          <select className={sel} value={f} onChange={(e) => setF(e.target.value)}>
            <option value="">choose...</option>
            {features.map((x) => <option key={x} value={x}>{x}</option>)}
          </select>
        </label>
        <label>Viral tracks tend to have
          <select className={sel} value={d} onChange={(e) => setD(e.target.value)}>
            <option value="">choose...</option>

            <option value="about the same">about the same</option>
          </select>
          values than non-viral ones
        </label>

          <select className={sel} value={v} onChange={(e) => setV(e.target.value)}>

<HypothesisBuilder />

### Activity (10 min)

In pairs, filter to three different genres and write down **two hypotheses** about which features drive the viral label. Keep them: in the next session the model will tell you which ones were right.

<Warning>
**Correlation is not causation.** If viral songs have high energy, that doesn't prove that raising a song's energy makes it viral. A dashboard shows *patterns*, not *reasons*.
</Warning>
